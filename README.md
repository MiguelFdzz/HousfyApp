# HousfyApp

*Este proyecto aún está en progreso*

Esta aplicación es un proyecto de fin de grado para DAM, es una aplicación de gestión del hogar enfocada a realizar con rapidez, organización y eficacia las diferentes tareas del hogar.

## Secciones

 - Página Principal
 - Página de Tareas
 - Página de Actividades
 - Página de Lista de la Compra
 - Página de Chat Grupal
